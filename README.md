# Polybar Configuration

This repository contains my personal Polybar configuration files.

## Overview

These configuration files set up Polybar with multiple modules for system monitoring, workspace management, and application shortcuts.

## Structure

- `config.ini`: Main configuration file
- `colors.ini`: Color definitions
- `modules/`: Directory containing module configurations
- `scripts/`: Utility scripts used by Polybar modules

## Installation

1. Make sure Polybar is installed:
   ```
   # For Arch-based distributions
   sudo pacman -S polybar
   
   # For Debian/Ubuntu
   sudo apt install polybar
   ```

2. Clone this repository to your Polybar config directory:
   ```
   git clone https://github.com/yourusername/polybar-config.git ~/.config/polybar
   ```

3. Start Polybar:
   ```
   polybar -r example
   ```
